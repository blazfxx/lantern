# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our pledge.** Participation in Lantern should be a harassment-free experience for everyone, regardless of age, body size, disability,
ethnicity, gender identity and expression, experience level, nationality, appearance, race, religion, or identity.

**Expected:** be respectful and constructive, critique ideas and code rather than people, assume good faith, help newcomers.

**Unacceptable:** harassment, insults, discrimination, sexualised language or attention, doxxing, personal attacks, sustained disruption.

**Scope.** All project spaces (issues, pull requests, discussions) and public spaces when representing the project.

**Enforcement.** Maintainers may edit, hide or remove contributions and may temporarily or permanently ban contributors for behaviour they
judge inappropriate. Report concerns privately through GitHub (*Report content*, or contact [@blazfxx](https://github.com/blazfxx)).
